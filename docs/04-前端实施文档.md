**Z.2 10-30 登录 403 修复（之前没写进本文档）**

针对 QAS demo7 登录时 403，详见 `功能计划书/项目进度/10月30日进度/部署说明_dist-deploy-20261030.md`：
- 取安全令牌改用 XHR，URL 带时间戳、请求头带 `If-Modified-Since: 1970`，不吃浏览器缓存的 304；
- 登录提示分开：401 =「账号或密码不正确」，403 =「账号密码已通过，但网关安全令牌校验未通过」；403 和服务不可用不计入「5 次失败锁 1 分钟」；
- 页面由 SAP 提供时（`/sap/bc/ui5_ui5/`、`/sap/bc/bsp/`）不再在登录前探测后端。

⚠ 那份说明的复核结论：403 更可能是 http 页面上浏览器拒存带 `secure` 的会话 cookie，不一定是令牌读不到。上传前先按说明里的 1 分钟控制台脚本验证；如果是 cookie 问题，要改成 https 访问或调整网关 cookie 设置，前端改不了。

## 〇-AW、2026-11-10 11.10 下午问题记录修复（引擎 0.17.0，配套《03》〇-AW）

来源：`功能计划书/项目进度/11.10进度/灵犀问题与需求记录汇总_20261110下午.docx`。#03（文件夹级汇总）、#09（直查底层表的行级权限）、#11（登录页）不在本次，另定方案。

| 记录 | 问题 | 改了什么 |
|---|---|---|
| #01 | 本地开发时新引擎报「请求来源与本系统不一致」 | 仓库里的本地代理 `local-middleware/zui5-simple-proxy/lib/proxy.js` 一直是旧版：只改 Host、没改 Origin，SAP 的来源校验就拒绝。现在转发时把 Origin / Referer 改成 SAP 地址。现场手工覆盖 `node_modules` 的做法不用再做（`npm install` 后是软链接，直接用仓库里的版本） |
| #02 | 没开思考的模型发「hi」报 `HTTP 404 - Invalid Function Import Parameter 'Think'` | SEGW 里 Think 参数没设可空 = 必填；前端在模型没开思考时不传它，网关就 404。改为：后端接口有 Think 参数就一直传，没开思考传空（后端空 = 按模型配置，不改行为）。`ChatService` 发 AnalyzeCode / AnalyzeTask 两处 |

## 〇-AT、2026-11-09 新引擎读写 Excel / Word（引擎 0.13.0，SAP 不用改）

**要解决的事**：新引擎读不了用户文件夹里的 Excel / Word（被当成二进制，模型看不到内容），也只能输出 .csv / .md。

**读**：`read_file` 遇到 Office 文件先转成文本，再按行分页给模型（和读文本文件一样用 offset / limit）。
- **Excel（.xlsx / .xlsm）**：每个工作表一节，每行开头是 Excel 行号，后面 A、B、C… 各列用 Tab 分隔；空行省略；日期格式的单元格转成 yyyy-mm-dd；隐藏工作表标注「隐藏」；公式取 Excel 存下的计算结果。超过 2 万行只转前 2 万行并说明。
  每个工作表后面再列出（需求文档常用）：合并单元格范围、图片的位置和名称（图片内容读不到）、文本框里的文字、批注（含作者），每类最多 50 个。
- **Word（.docx）**：段落一行一段；标题（含中文 Word 的「标题 1」样式）加 #，列表加 -，表格转成 `| a | b |`，图片标 [图片]；页眉页脚、批注、修订删除的字不转。
- **PowerPoint（.pptx）**：每页一节，文本框和表格里的文字一段一行（只读，不能新建）。
- 旧格式 .xls / .doc / .ppt、加密文件读不了，提示用户另存；单个文件上限 30 MB。`grep` 不搜这几种文件里的内容。

**写**：有文件夹（且不是只读）时多两个工具，都是**整份新建**，不在原文件上局部修改：
- `create_excel_file`：模型给工作表名、表头、数据行；表头加粗、冻结首行，列宽按内容；数字存成数字（能求和），字符串一律存文本（料号等前导 0 不丢）。
- `create_word_file`：模型给简单 Markdown（# 标题、- / 1. 列表、| 表格 |、**粗体**），生成带标准「标题 1~3」样式的 A4 文档。
- 写前和写文本文件一样弹确认（确认框里显示生成内容转成的文本；覆盖已有文件时能对比旧内容）、覆盖前备份到 `.lingxi/备份/`、记修改记录、能撤回。
- 系统说明要求：改用户已有的 Excel / Word 时另存新文件（如「原名_修改.xlsx」），用户明确要求才覆盖。
- `write_file` / `edit_file` 仍然不能写 .xlsx / .docx（模型直接写会把文件写坏），被拒时提示改用上面两个工具。

**存到文件夹**：`save_result_to_folder` 的路径写成 .xlsx 就存 Excel。数据仍由 SAP 直接给、不经过模型；普通数字转成数字，前导 0 的编号、超过 15 位的数、带千分位的值、日期都保留原样；SAP 负号在后（`12.5-`）的转成负数。

**实现**：不引第三方库——Office 文件就是 zip + XML，用浏览器自带的 `DecompressionStream` / `CompressionStream`（Chrome / Edge 103 起都有）解压、压缩，XML 按需取。新文件 `agent-bundle/src/office.js`；引擎包只多约 30 KB。

## 〇-AD、2026-11-05 参数卡多重选择（仿 SAP GUI，纯前端）

**要解决的事**：多值参数（工厂、料号、机种……）要填很多值时，从 Excel 复制一列贴进输入框，浏览器会把换行吞掉，值粘成一串；也没有像 SAP GUI「多重选择」那样的地方粘贴、查看、修改一长串值。

- **直接粘贴**：往多值参数的输入框粘贴含换行或 Tab 的内容（Excel 一列、一行多格），自动拆成多个值、并入已有的值、去掉重复。
- **多重选择按钮**：多值参数输入框右侧一个方块按钮（有 2 个以上值时显示个数）→ 粘贴面板：大文本框每行一个值，可直接 Ctrl+V 粘贴一整列；下方实时显示「共 N 个值（去掉重复 M 个）」；「清空」「确定（N）」。页面是 https 或 localhost 时多一个「从剪贴板粘贴」（http 访问时浏览器不开放剪贴板，用 Ctrl+V）。

## 〇-Q、2026-10-31 报表执行结果在切换 / 刷新后丢失（10.31 记录 #01）

<mark>**现象**：QAS demo7 上执行 ZDPMM003E 成功（9 行结果表），之后再打开这个会话，结果表不见了，只剩文字消息。</mark>

**原因**：同一页面里来回切换会话，结果在本页缓存里，不会丢；丢的是**页面重新加载或缓存被清空之后**（刷新、重新登录、别的窗口改了登录或连接设置）。这时要靠 DATA-01（〇-J）的恢复链路：`Tasks` → 每个任务的 `TaskContext`（结果索引）→ `ReportResult` 取明细。其中 `TaskContext` 在 DATA-01 之前前端从没调用过，SEGW 清单写的是 POST，前端用的是 GET，这一步在 SAP 上从没验证过，失败时又只在控制台留一行警告，所以界面上什么都看不出来。

**改了什么（只改前端，后端 / SEGW / 配置都不动）**：
1. `Tasks` / `TaskContext` 先用 GET；被网关按 HTTP 方法拒绝（405 / 501 / "not allowed"）时自动改用 POST 再试一次，本页之后直接用 POST（`ChatService._taskRead`）。两个都是只读接口，重发没有副作用。
2. 结果在本页显示过一次，就在本机记下结果号（只记编号、标题、行数，不存数据；每个会话最多 20 个）。服务器索引查不到时，同一浏览器仍按结果号走 `ReportResult` / `FioriReportResult` 取回，插回原位置。这两个接口执行时就在用，现场是通的。
3. 取不回的结果（过期、已删、接口报错），在原位置留一行说明：「这里原有一份结果「…」，重新打开会话时没能取回：原因」。后端明确说结果已没了的，以后打开会话直接显示说明，不再重复去取。
4. 查结果索引失败的原因会在控制台打出 `[DATA-01] 会话结果索引读取失败: Tasks/TaskContext: …`。

**还原不了的**：「报表运行 xxxx」三态步骤条是执行时的实时进度，重新打开后不再画出来；结果卡第一行已经写了运行号（「报表结果（运行 0050569C，共 9 行）」）。换电脑或清了浏览器数据时，只能靠服务器索引（第 1 条）。

**部署**：`npm run build` 后 `npm run build:deploy`，上传精简包（同 10.30 部署说明）。

**验收**（Chrome，F12 → Network，过滤 `Task`）：
1. 在 Agent 里执行一张报表，等结果表出来；按 F5 刷新，打开这个会话：结果表回到原位置。
2. 看 Network：依次有 `Tasks`、`TaskContext`、`ReportResult`。如果 `TaskContext` 先出现一个 405 的 GET、紧接着一个 POST 成功，说明现场 SEGW 是 POST，前端已自动切换，**请把这个现象告诉开发**（以后可以直接改成 POST）。
3. 换一台电脑（或无痕窗口重新登录）打开同一个会话：结果表也应回来；回不来时 Console 里 `[DATA-01]` 那行原因请截图给开发。

1. SICF → 逐层展开 `default_host → sap → bc → ui5_ui5 → sap → zai_chat_demo1` → 右键**激活**（首次上层 `ui5_ui5` 未激活会提示连带激活，确认即可——标准节点不影响系统）；

## 七、回滚

- **代码级**：`git checkout <旧tag>` → `npm run build` → 重打 zip → 按第四章重新上传覆盖；
- **传输级**：STMS 不能"撤销导入"，回滚 = 上传旧版本内容的新请求（同代码级）；
- 所以**每次部署的 zip 都要留着——它们就是回滚包**（存档见仓库 `02_部署产物/`）。

## 八、Git 版本管理（第一次做一次）

```bash
git init && git add . && git commit -m "init: 基线"
```

`.gitignore` 必须先建（否则首次提交 300MB+）：`node_modules/`、`dist/`、`.docgen/`、`.v2c/`、`*.log`、`*.zip`、`Thumbs.db`。

- **分支**：`main`（稳定可构建）+ `feature/xxx`（实验线，做完合回删掉）；原则：main 上每个 commit 都能构建出可用 dist；
- **部署快照**：每次对外部署前打 tag：`git tag -a v8.3-dist-20260905 -m "V8.3 部署快照"`，zip 用同名保存 → 三个任意还原（代码 `git checkout tag` / 部署物翻 zip / 历史 `git log`）；
- 家里机 ↔ 公司机只传 zip；单人项目不值得搭 git 远端。

## 九、备选部署方案与依赖说明（答疑）

- **方案 B（静态服务器 nginx/IIS）**：dist 放独立 VM，反代 `/sap` 到网关（保留路径前缀），config.js host 留空走同源反代；需额外申请 VM/域名/证书/端口放通。前端代码零改动，公司统一门户要求时再迁；
- **Node.js**：仅构建时需要，部署产物纯静态，服务器不装 Node；
- **UI5 运行时**：随包自带方案已与服务器版本彻底无关；唯一仍依赖服务器的是 ICF 登录；
- **浏览器**：Chrome/Edge 近两年版本（fetch/AbortController/CSS :has），不支持 IE11；
- **dist 瘦身**（传输受限时，删了没法本地调试）：删全部 `*.map` 与 `*-dbg.js`；删 `resources/sap/ui/test`、`sap/ui/commons`、`sap/ui/ux3`、`sap/tnt`、`sap/ux`；⚠️ 不要动 `sap/ui/core`、`sap/m`、`sap/ui/layout`、`sap/ui/unified`、`sap/base`、`thirdparty/` 与两套 theme 目录。

## 十、FAQ

| 问题 | 处置 |
|---|---|
| 打开页面 404 | SICF 节点没激活（第五章）；或 zip 多套一层目录（§3.1 重打） |
| 白屏，Console 报 sap-ui-core 加载失败 | dist 没带运行时（检查点 1）或 ui5Src 配错 |
| 一直停在"演示模式" | 后端不可达：服务没发布/ host 非空/网络不通；F12 看 $metadata 状态码 |
