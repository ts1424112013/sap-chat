### 类 1：SE24 旧解析器语法雷（7z 源码从未通过 SE24 编译）

## 三、SE24 vs ADT 编译器差异（根因总表）

| 维度 | ADT/Eclipse | SE24 Class Builder |
|---|---|---|
| STRING 写入位 offset | 自动处理 | 报错 |
| STRING 无 length offset | 允许 | 报错 |
| STRING length 位算术表达式 | 部分接受 | 报错 |
| CHAR 实参 → string 引用形参 | 自动按值转换 | 报错（要求显式 string） |
| 静态 CALL FUNCTION 参数名/类型 | — | 编译期不查，运行时 dump |
| 30 字符方法名截断 | 一致（SEGW 生成侧） | 一致 |

**结论**：无 ADT 的内网环境下，SEGW 新批次代码必须用本目录 SE24 修正版部署。

## 五、给后来者的三条铁律

1. **7z/历史源码包 ≠ 可激活代码**——SQL_GUARD/SQL_EXECUTOR/DDIC_TOOLS/AGENT_GUARD/DPC_EXT/TOOL_REGISTRY 六个类在历史包里从未通过 SE24 编译；以后新批次代码必须先在 SE24 完整走一遍激活。
2. **SE24 旧解析器三条 STRING 铁律**：写入位禁子串赋值、无 length offset 禁、length 位置禁表达式——**新写代码一律先算入变量**。
3. **FORM 局部数据要跨 FORM 返回，必须 CREATE DATA（堆）**——`GET REFERENCE OF` 栈变量出 FORM 即 FREED。
