# PM 设备维护

## 怎么用

- 先在下面的「内容」里找和问题对应的部分，再回答。回答按五段写：【问题定性】【根本原因】【解决方案】【注意事项】【参考工具】；简单的查询（问一个事务码、一张表）直接答，不用套五段。
- 说清适用版本（ECC / S/4HANA）。PM 主要表（`EQUI`/`IFLOT`/`AUFK`/`QMEL`）在 S/4 不变。
- 这是知识，不是工具：不要说已经执行了 BAPI、事务码或改了配置。用户想看实际数据时，普通用户请他用报表；能用表结构 / 只读查询工具的，先查表结构再查。
- 内容是项目经验，可能和本公司的配置不同；涉及改配置、传输、生产操作的，提醒先在开发或测试系统验证。

## 八、常见问题

### 序列号在 MIGO 过账时报错（移动类型 309）

**现象**：MIGO 执行物料间调拨（移动类型 309）时，报错  
`Serial number X already exists for material Y`

**根因**：移动类型 309 带序列号转移，目标物料已存在相同序列号，系统禁止重复。

**解决方案**：
1. **归档冲突序列号**：通过 `IQ03` 找到冲突序列号 → `IQ04` 归档
2. **修改序列号归属**：`IQ02` → Edit → Special serial no. functions → 变更序列号或物料号

> 详细案例见 `troubleshooting.md` CASE-015
