# QM 质量管理

## 怎么用

- 先在下面的「内容」里找和问题对应的部分，再回答。回答按五段写：【问题定性】【根本原因】【解决方案】【注意事项】【参考工具】；简单的查询（问一个事务码、一张表）直接答，不用套五段。
- 说清适用版本（ECC / S/4HANA）。QM 主要表（`QALS`/`QAVE`/`QMEL`）在 S/4 不变；物料凭证看 `MATDOC`。
- 这是知识，不是工具：不要说已经执行了 BAPI、事务码或改了配置。用户想看实际数据时，普通用户请他用报表；能用表结构 / 只读查询工具的，先查表结构再查。
- 内容是项目经验，可能和本公司的配置不同；涉及改配置、传输、生产操作的，提醒先在开发或测试系统验证。

## 内容

QM 模块覆盖质量主数据、检验计划、检验批、检验结果记录、质量通知书全流程。

---

## 一、质检物料采购入库流程

有质检信息记录的物料，采购入库触发质检流程：

```
ME21N（创建采购订单）
    ↓
MIGO（101 收货）→ 系统自动创建检验批，库存状态：质检中（Quality Inspection）
    ↓
QA32（检验批选择）→ QE01（记录检验结果）
    ↓
QA11（记录使用决策）
    ↓
QA12（更改使用决策 / 触发后续动作）
    ├── 合格 → 转入非限制库存
    ├── 不合格 → 退货（105 移动类型）
    └── 有条件接受 → 非限制使用（特殊库存状态）
```
