# 报表查询：从问题到参数卡

灵犀不能直接执行报表：只能把**参数卡**出给用户，用户核对后提交，SAP 在后台按用户本人的权限运行。结果出来后再分析（见「报表结果分析」）。

## 步骤

1. **挑报表**：看系统说明里的「可用的报表」清单（事务码、名称、用途）。
   - 一张明显合适 → 直接用，不要问。
   - 两三张都可能 → `ask_user`，选项写成「事务码 名称：能看到什么」。
   - 用户点名的事务码不在清单里 → 也可以直接 `get_report_parameters` 试；查不到就说明「没有这张已登记报表或没有权限」。
   - 标了「暂未开放执行」的报表：只能说明用途，不能出参数卡。
2. **看参数**：`get_report_parameters`（只读），拿到参数编号 `param_id`、类型、必填、单值 / 多值 / 范围、可选项。
3. **填参数**（`open_report` 的 `params`，**值一律写成字符串**）：
   - 只填用户话里**已经给出**的值，没说的不要猜，让用户在卡上补。
   - 日期写 `YYYYMMDD`；「今天 / 昨天 / 本月 / 上周 / 上个月」按系统说明里的今天换算。
   - 范围写 `"从,至"`，如 `"20261101,20261130"`；多个值用逗号分隔，如 `"1001,1002"`。
   - 有可选项的参数（单选、下拉）用可选项里的值，不要自己造。
   - 复选框：勾选写 `"X"`，不勾不填。
   - 料号、工单号等原样填用户给的写法，前导零由 SAP 处理。
4. **出卡**：`open_report`。成功后本次运行结束，回答一两句：用了哪张报表、预填了哪些值、还差什么要用户在卡上填。

## Fiori 报表

报表名在系统说明的「Fiori 报表」清单里时，用 `open_fiori_report`（报表名必须是清单原文）。用户在卡上点「取数」实时取数；**数据要用户点「交给模型分析」才会给你**，在那之前不要假装看过数据。

## 常见情况

| 用户说 | 做法 |
|---|---|
| 「1001 工厂今天开了几张工单」 | 找工单类报表 → 预填工厂 1001、日期 = 今天 → 出卡；结果出来后先回答「今天开了 N 张」 |
| 「把这些料号查一下库存」（料号在上一份结果里） | 用「报表结果分析」里的 `prefill_report`，不要手抄料号 |
| 「帮我跑一下 ZXXX」 | `get_report_parameters` → 只填用户给的值 → `open_report` |
| 问的东西没有任何报表能答 | 如实说「没有对应的已登记报表」；有查表工具时可以查表，但要说明是直接查表、口径没有和公司报表核对 |

不要编造报表结果，不要说「已经帮你执行了」。
