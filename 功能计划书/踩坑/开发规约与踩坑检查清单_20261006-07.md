## 1. 架构速览（30 秒版）

### 前端数据链路
```
ChatService.sendAgent → AnalyzeAgent(OData FI)
  → _sanitizeAnalysis 解析 AnalysisJson(白名单复核)
    → charts 为空时 _autoCharts 兜底(V1.3.1: 前端SUM聚合+追加"自动汇总"数据集)
      → App.controller _buildAnalysisHtml → _chartToSvg(原生SVG bar/line/pie, 复用PreconfiguredCharts管线)
```
- AnalysisJson 结构：`{ datasets:[{name,status,error,columns:[{name,label,numeric}],rows,totalRows,truncated,elapsedMs,source}], charts:[{type,title,dataset,x,y}], findings, summary }`
- chart.x/y 必须引用该 chart.dataset 数据集的列名（GUARD 校验口径）

### 后端查询双通道
| 通道 | 实现 | 白名单机制 | JOIN |
|---|---|---|---|
| 数据分析工具(协议查询) | ZCL_AI_DATA_ANALYSIS_SERVICE | 能力目录(实体白名单+字段白名单) | ❌ 单实体 |
| run_sql(动态SQL) | ZCL_AI_SQL_GUARD/EXECUTOR | **黑名单制**(黑名单外全放) | ✅ 支持(FROM/JOIN 表逐一过 DDIC+黑名单+权限) |
- 能力目录注入模型提示词（"当前支持: MARA, ZIDPPP099"），模型优先走协议查询，复杂需求退 run_sql。**注册新表不影响 run_sql**（两套校验物理隔离）。
- run_sql 的成败依赖模型 Open SQL 水平（V4 Flash 会写错语法，如 COUNT(*) INTO TABLE）——单表统计优先协议查询。

### 部署拓扑
- 开发库 sapgls4dev（SE24 手工部署）/ 测试库 sapgls4qas（STMS 传输）
- **传输只带走：服务定义+MPC/DPC类+ICF节点(未激活态)。系统别名分配不随传输，QAS 必须手工配。**

## 2. 铁律（⭐=实锤炸过）

### 2.1 SE24 Class Builder 与 ADT 编译器差异 ⭐（2026-10-06 全日集中爆发）
开发机 ADT"实测通过"≠SE24 能激活。**内网部署一律用 SE24 修正版源码，逐类手工贴+核对版本头**。已知不兼容模式：

| # | 模式 | 对策 |
|---|---|---|
| 1 | `SHIFT x LEFT LEADING DELETING LEADING` 非法组合 | 改单一种形式 |
| 2 | **offset/length 位置放 strlen()/算术表达式**（`x+strlen(y)`、`x+lv_a(lv_b-lv_c)`、`lv_x+1(1)`）⭐三犯 | 一律先算进中间变量 |
| 3 | **STRING writer 位置子串赋值**（`lv_str+a(b) = x`） | 中转变量/CONCATENATE |
| 4 | **STRING 无 length 的 offset 读取传参**（`foo( iv_raw+lv_off )`） | `substring( val= off= )`；带 length 的读取可过 |
| 5 | `|{{ }}` 转义模板、嵌套模板 `sep = |, |` | 改反引号字符串拼接 |
| 6 | **类属性笔误**（`cl_abap_char_utilities=>cr_char` 不存在） | 用前查类属性存在性 |
| 7 | **CHAR 实参直传 `TYPE string` 引用形参**（SELECT @DATA 内联变量、DDIC 字段 CHAR30/60）⭐ | 调用处一律 `CONV string( ... )`；反向(CHAR 形参收 string 实参)同样要 CONV |
| 8 | 方法内同一变量名重复内联声明（两处 `DATA(ls_tool)`） | 显式 DATA 声明一次 |
| 9 | **CALL FUNCTION 运行时形参名不匹配**（编译期不查！VIEW_AUTHORITY_CHECK 的 `view=` 应为 `view_name=`；VIEW_NAME CHAR30 引用形参收 string 实参也要 CONV）⭐ | FM 调用前逐参数核对 SE37 签名；参数位置不允许 CONV 表达式→先赋中转变量(显式 CHAR 类型) |
| 10 | `cr_data->* = lt_result` 泛型引用解引用赋值 | FIELD-SYMBOL 三段式：CREATE DATA 堆对象 → ASSIGN → 拷贝 |
| 11 | 异常名截断（`no_clientindep_authority` 写成截断名会被忽略→运行时二次炸） | 异常名对齐 SE37 全名 |

### 2.2 FORM 栈引用失效 ⭐
`GET REFERENCE OF` 指向 FORM 内局部表，PERFORM 返回后栈帧回收 → 引用 FREED → IS NOT BOUND。**铁律：跨过程传数据容器必须 CREATE DATA（堆），在 FORM 内 CREATE 后拷贝，禁止 GET REFERENCE OF 栈上变量带出过程。**

### 2.3 copy_data_to_ref 字段映射（OData 输出）⭐（2026-10-07 图表不出根因）
`copy_data_to_ref` 按属性名↔字段名**大写精确匹配，不容忍下划线**：结构字段 `session_id` ↔ SEGW 属性 `SessionId`(SESSIONID) **匹配失败且静默置空，不报任何错**。
- **铁律**：新增 ComplexType/FunctionImport 后，**先用 Gateway 客户端验证全字段回显**再测业务；返回结构与 SEGW 属性名不一致时，用**无下划线中间结构**逐字段赋值后再 copy（见 DPC_EXT ANALYZEAGENT 分支 V13.1 范例）。
- **检查项**：响应里"带下划线字段全空、无下划线字段有值" = 此坑指纹。

### 2.4 SEGW 建模
- ⭐删 EntityType 不自动删 EntitySet → 重建报 "Entity Set name already exists"，到 Entity Sets 节点删孤儿。
- ⭐**EntitySet 名 ≤15 字符**（17 字符 + _GET_ENTITYSET = 32 > 30 上限，DPC 基类方法名自动截尾掉尾字母 → DPC_EXT 重定义必须用截断名 `agentcapabilitie_get_entityset`）。
- ty_agent_result.analysis_json 等结构字段与 SEGW 属性一一核对（03 文档曾有漏项导致从零重建会静默丢图表能力）。

### 2.5 激活顺序依赖 ⭐
13 类拓扑顺序（修订高亮版文档 5.1）：LLM_CLIENT → CODE_PROVIDER → TOOL_REGISTRY → DOMAIN_CARDS → SQL_GUARD → **DATA_ANALYSIS_SERVICE(第⑥位,被 SQL_EXECUTOR/AGENT_GUARD 引用)** → SQL_EXECUTOR → DDIC_TOOLS → AGENT_GUARD → INVENTORY_TOOLS → CHAT_SERVICE → AGENT_SERVICE → DPC_EXT。或全贴完统一激活。

### 2.6 SE24 重贴覆盖历史修复 ⭐（2026-09-05 实证）
整类粘贴旧版会把历史修复覆盖掉。**铁律**：①所有交付源码带版本头注释与核对标记（grep 验证，见 §5 版本标记表）②重贴后先核对标记再激活③激活后 grep 1~2 个关键修复特征行。

### 2.7 JS 侧（前端）
- ⭐`parseFloat("2026-09-01")`=2026，**日期串被前缀解析误判数值**——数值判定必须完整形态校验 `/^-?\d+(\.\d+)?$/`（ChatService._autoNumVal）。
- AnalysisJson 解析 try/catch 静默降级，不弹错；后端有 charts 时以前端返回为准，推断兜底仅在 charts 为空时生效。
- 部署验证：构建后 grep dist/Component-preload.js 特征函数名（§5）。

### 2.8 SAP 行为与取证
- ⭐**未激活的 ICF 节点返回 401 认证挑战（不是 404）**——传输后"登录框循环"先查 SICF 激活状态，别怀疑密码。
- ⭐**系统别名不随传输**：QAS 需手工 /IWFND/MAINT_SERVICE 分配（错误 /IWFND/CM_COS/064 = 别名缺失；RFC 目标 NONE+本地别名）。
- **GW 框架把 ABAP 运行时异常 catch 转 HTTP 500**，ST22 常无记录——去 **/IWFND/ERROR_LOG** 看根因（CX_SY_* 类错误都在那）。
- ZAI_SQL_LOG 审计表注意 MANDT 赋值（漏赋值时 SE16 按 470 查不到，造成"0条"假象）。
- ⭐**读图纪律**：低分辨率 SAP 截图字段名易错（WERKS 误读 WORKS、009/099）——关键字段名结论必须请用户确认或看原文文本。
