# LingXi 灵犀 · 彩色运行动效

这版把标志的三部分分配为不同色系：

- 主弧：柔和紫色 → 蓝色 → 青色。
- 上叶翼：青绿 → 薄荷绿 → 芽绿。
- 下叶翼：蜜桃橙 → 珊瑚色 → 玫瑰粉。

运行时叶翼会交替大幅展开，主弧跟着起伏。上叶翼最大展开约 16 度，下叶翼约 16 度，节奏约 2.4 秒一轮；思考节奏约 4.2 秒一轮，幅度稍小。停止时用约 0.38 秒柔和回位。

用浏览器打开 **叶翼彩色动态预览.html** 即可查看。文件内包含全部图形和动画，离线也能使用。

预览支持静止、思考、运行切换，以及暂停、单次运行和深色背景。页尾可下载当前状态的彩色标志。

`exports/` 内三份带「叶翼彩色」的 SVG 对应静止、思考和运行。SVG 是可以放大而不模糊的矢量图，动画已包含在文件中。

已检查三部分的不同颜色、运行中的动画、深浅背景、手机显示以及三种状态的导出内容。
