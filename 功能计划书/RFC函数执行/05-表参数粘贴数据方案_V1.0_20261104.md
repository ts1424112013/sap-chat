# 函数表参数：粘贴数据（方案与开发计划）

版本：V1.0；编写日期：2026-11-04（Asia/Shanghai）。用户确认「做一下这个功能」。

## 1. 问题

有些函数的输入是一张表（多行、每行一个或多个字段），比如物料清单、工厂 + 物料对照。目前只有「范围表」（SIGN / OPTION / LOW / HIGH）能登记成多值；其余表参数、结构参数在登记时被跳过，必填的会让整个函数登记不了。

## 2. 方案：参数卡上粘贴数据

用户从 Excel / SAP ALV 复制几行，粘到参数卡里；执行时一行变成表里的一条记录。

### 2.1 哪些参数算「表参数」

| 函数参数 | 现在 | 改后 |
|---|---|---|
| IMPORTING / CHANGING 的表（行是扁平结构或单字段） | 不登记 | 登记成表参数（`SEL_KIND = T`、`DATA_TYPE = TABLE`、`MULTI_VALUE = X`），必填照接口 |
| IMPORTING / CHANGING 的扁平结构 | 不登记 | 登记成表参数，**只收一行**（`MULTI_VALUE` 空） |
| TABLES 表（非范围） | 不登记（多半是输出） | 名字以 `IT_` / `I_` / `IN_` / `INPUT_` / `T_IN` 开头，或在 `ZAI_RPT_REG` 新选项「当输入的 TABLES 表」里点名 → 登记成表参数（选填）；其余仍当输出 |
| 行里有嵌套表 / 引用等复杂字段 | 不登记 | 不变（写原因；必填的照旧挡住登记） |

「扁平」= 行结构展开 include 后每个字段都是单值字段（字符、数字、日期等）。默认主结果不会再选到当输入的 TABLES 表。

### 2.2 数据格式

参数值是 JSON「数组的数组」字符串，第一行是字段名，后面是数据：

```
[["MATNR","WERKS"],["100234","1000"],["100235","1010"]]
```

- 单字段行（如 `TABLE OF MATNR`）的字段名写 `TABLE_LINE`。
- 前端负责把粘贴的内容变成这个格式；数据分析里模型一期不传表参数（见 §2.6）。
- 上限：1000 行，整个值 40 万字符。

### 2.3 前端（`AskCard`）

- 表参数显示成粘贴框（多行文本框），框上方一行列说明：「列：物料 MATNR / 工厂 WERKS …」（来自 `ValueHelp` 元数据的 `columns`，见 §2.5；没部署时只提示「第一行写字段名」）。
- 粘贴后立即解析（Tab 分列、换行分行），下方出预览小表：前 8 行 + 「共 N 行」，表头写对上的字段。
- 列对应：
  - 第一行能对上字段（字段名或中文名，不分大小写）→ 当标题，按标题对字段，顺序随意；对不上的标题列标红、不提交。
  - 第一行对不上 → 当数据，按列定义顺序依次对应。
- 结构参数（只收一行）粘了多行 → 提示只用第一行。
- 必填没粘、或一列都没对上 → 提交时标红，跟必填未填一样。
- 回显：「N 行」。
- 值太长（URL 超限）时 `startReportRun` 走长文本通道（`ChatTexts`，和问题框同一个），`StartReportRun` 收到 `@@ZAI_TEXT:` 换回原文。

### 2.4 后端

| 对象 | 改动 |
|---|---|
| `ZCL_AI_RFC_EXEC` V1.2 | `classify` 算出行的可填字段数（`cols`，0 = 不支持）；`default_result` 跳过当输入的 TABLES 表；新公开方法 `table_input_name`（名字规则）、`parse_rows`（手写 JSON 数组解析，不用正则）、`table_columns`（列定义：字段 / 文字 / 类型 / 长度）；`bind_core` 表参数 → `fill_table`：按表头对字段、逐格 `set_value`（转换例程、大写、日期；数字去千分位），错误写清「第 n 行 字段名: 原因」；`list_callable` 跳过有必填表参数的函数、说明里不列表参数 |
| `ZCL_AI_RPT_SCANNER` V1.3 | `scan_function` 按 §2.1 登记表参数；新参数 `it_tin`（点名当输入的 TABLES 表） |
| `ZAI_RPT_REG` V1.2 | 新选项 `S_TIN`「当输入的 TABLES 表」 |
| `ZCL_AI_REPORT_SERVICE` V1.0.17 | `parse_flat_kv` 改成手写扫描（原正则对长值会报「正则过于复杂」，整串参数丢失）；`validate_params` 对 `SEL_KIND = T`：必填检查 + 形如 `[[…]]` + 长度上限，原样进快照（细校验在函数预检） |
| `ZCL_AI_VALUE_HELP` V1.1 | 元数据给表参数带 `columns`（来自 `ZCL_AI_RFC_EXEC=>table_columns`） |
| `ZCL_ZAI_CHAT_DPC_EXT` V15.14 | `STARTREPORTRUN` 的 `ParamsJson` 以 `@@ZAI_TEXT:` 开头时经 `resolve_text` 换回原文 |

细校验时机：提交后 `EXEC_SAP` 的函数预检（`precheck` → `bind_core`）就会跑一遍，错误写在运行步骤条上（「函数调用预检失败: 参数 物料清单 第 3 行 数量: …」），不会进后台作业。

### 2.5 列定义怎么给前端

不新增表、不新增函数导入：`ValueHelp` 元数据（`ParamId` 空）里，表参数多一个 `columns: [{name, label, type, len}]`，按函数接口现场读（RTTI），最多 60 列。

### 2.6 一期不做

- 数据分析里模型调用时传表参数（工具参数现在只收扁平值）；有必填表参数的函数不进数据分析可调清单。
- 表格单元格里的搜索帮助、在卡片里逐格编辑（改数据就重新粘贴）。
- 报表（选择屏）没有表参数，不涉及。
