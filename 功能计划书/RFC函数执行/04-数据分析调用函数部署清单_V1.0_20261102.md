## 2. 新建 `Z_AI_RFC_RUN`

按 [Z_AI_RFC_RUN.abap](../../backend-abap/Z_AI_RFC_RUN.abap) 头注释操作：

1. SE37 → 函数模块 `Z_AI_RFC_RUN` → 创建，函数组 `ZAI_ODATA`（和 `Z_AI_ODATA_GET` 放一起）。
2. 「属性」页：**远程启用模块**（必选）。
3. 导入（全部值传递）：`IV_REPORT_ID` STRING、`IV_PARAMS_JSON` STRING、`IV_MAX_ROWS` INT4 缺省 2000。导出（全部值传递）：`EV_RESULT` STRING、`EV_ERROR` STRING。不建例外。
4. 源代码页只贴 `FUNCTION … ENDFUNCTION` 之间的正文，激活。

### 激活 / 运行时可能遇到的

| 现象 | 原因 / 处置 |
|---|---|
| 数据分析里调用报「函数结果解析失败」 | `/ui2/cl_json` 还原嵌套数组（`ROWS` 是数组的数组）不行。SE37 单测 `Z_AI_RFC_RUN` 看 `EV_RESULT` 是否正常；正常就是还原的问题，告诉我改成手工拆 |
| 调用报「函数调用中断(SYSTEM_FAILURE)」 | 目标函数在新会话里 dump 了，ST22 看短文本；或用户缺 `Z_AI_RFC_RUN` 所在函数组的 S_RFC（RFC_TYPE = FUGR, RFC_NAME = ZAI_ODATA, ACTVT = 16，和 Fiori 取数同一条） |
| 「不是远程启用」 | `Z_AI_RFC_RUN` 属性页没选远程启用模块 |
| 数据分析里看不到 call_function | 开关 `RFC_IN_DATA = N`；或没有 `REPORT_KIND = FUNC`、活动、开放执行、`EXEC_MODE` 不是 `JOB`、且当前用户有授权的函数 |

## 4. 现场验证

用《02》§5 登记好的那个函数（D1）。

| # | 操作 | 预期 |
|---|---|---|
| 1 | SE37 单测 `Z_AI_RFC_RUN`：`IV_REPORT_ID` = 函数的登记编号，`IV_PARAMS_JSON` = `{"iv_werks":"1000"}`（键 = 参数编号小写） | `EV_RESULT` 以 `{"NAME":` 开头，有 `COLUMNS` / `ROWS`；料号没有前导零、日期是 YYYY-MM-DD |
| 2 | 数据分析里问一个这个函数能直接答的问题 | 步骤条「调用函数：<名称>（<调用名>），共 N 行」；下面出结果表格 / 图表；回答里的数字和结果一致 |
| 3 | 问的时候不给必填条件（如不说工厂） | 模型先问工厂，或调用被拒后改了再调；不会编一个工厂 |
| 4 | 问一个要「函数 + 补查」的问题（如函数结果加供应商名称） | 先调函数，再 `describe_table` / `run_sql` 补查 |
| 5 | SE16 把函数的 `EXEC_MODE` 改成 `JOB`，再问 | 数据分析里不再调用它（工具说明里没有），可以走报表执行 |
| 6 | `ZAI_CHAT_CFG` 加 `RFC_IN_DATA = N`，再问 | 数据分析里没有 call_function；删掉这行恢复 |
| 7 | 用会让函数报例外的条件 | 步骤条「调用函数失败：… 返回例外 …」，模型如实说明 |
| 8 | 普通用户（`RPT_ACL_ENABLED` 开着、没分配这个函数） | 工具说明里没有它；硬说调用名也被拒 |
