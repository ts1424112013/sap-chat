## 3. 可选对象的手工改法（现场版本落后时用）

- **AGENT**：`exec_read_source` 里把 `对象名不合法(只能是程序名/事务码/类名)` 改成 `…/类名/函数模块名)`；`build_report_intro` 里 `ev_answer = |【报表 { ls_def-report_name }】…` 那段换成仓库版的 `IF to_upper( ls_def-report_kind ) = 'FUNC'. … ELSE. … ENDIF.`。不改也能用，函数卡片的标题会写「报表」。
- **工具注册表**：`read_program_source` 的 `description` 第一句加「/函数模块」，`args` 示例加 `Z_AI_ODATA_GET`。不改也能读函数源码，只是模型不一定想到直接给函数名。
- **领域卡**：CODE 域卡第 1 条加「函数模块直接给函数名，返回接口 + 本体源码」。同上，不改也能用。

## 4. 权限与配置

- **S_RFC**：执行函数时按**当前用户**检查 `S_RFC`（RFC_TYPE = FUNC + 函数名，或 FUGR + 函数组，ACTVT = 16），任一通过即可。普通用户可能没有 Z 函数组的 S_RFC，二选一：
  - 给角色加 S_RFC（推荐，符合「助手里能做的不能比 SAP 里多」）；
  - 或 SM30 在 `ZAI_CHAT_CFG` 加 `RFC_AUTH_CHECK = N` 关掉这道检查（报表授权 `ZAI_RPT_ACL` 和函数自己的权限检查照常生效）。
- **后台作业**：和报表执行一样，用户要能释放自己的作业（S_BTCH_JOB RELE）。能跑报表的用户就够了。
- **报表授权**：函数登记是 `ZAI_RPT_DEF` 的一行，`RPT_ACL_ENABLED` 开着时要在「设置 → 用户管理」里给用户分配（SRC_TYPE = REPORT，编号 = 调用名）。

## 5. 登记与验证

### 5.1 登记一个函数（SE38 `ZAI_RPT_REG`）

1. 「函数模块名」填函数名；函数名超过 20 位或不是 Z 开头（如 `BAPI_PO_GETITEMS`），在「事务码别名 / 调用名」填一个 Z 开头的名字（如 `ZF_PO_ITEMS`）。
2. 选「扫描预览」运行，看：
   - 参数行（+ 登记 / - 不登记及原因）；
   - 说明里的 `✗`（提交 / 写库 / 异步写入，有就不能登记）、`?`（函数名疑似写入类）、`!`（只提示）；
   - 「主结果」是不是想要的那张表，不是就在「函数主结果参数」填对的参数名。
3. 选「写入登记」，勾「新报表登记后立即开放执行」，去掉「只演练」再跑一次，弹窗点写入。
4. 函数名疑似写入类但确认只读：勾「函数名疑似写入类也登记」。源码里有 `✗` 的不能强制。

### 5.2 现场验证（D1 定的函数）

| # | 操作 | 预期 |
|---|---|---|
| 1 | Agent「代码分析」问「`<函数名>` 是做什么的」 | 读到接口摘要（参数 / 类型 / 必填）+ 函数源码，回答引用行号 |
| 2 | 「报表执行」目录刷新 | 出现「函数」分类，那一行是函数图标 |
| 3 | 点执行，填参数提交 | 步骤条走完，结果表格列标题是字典文字 |
| 4 | 用一个查不到数据的条件再跑 | READY，0 行 |
| 5 | 用一个会让函数报例外的条件（如不存在的工厂） | FAILED，步骤条写「函数 … 返回例外 …」或消息原文 |
| 6 | 结果点「交给模型分析」、拿它做组合分析 | 和报表结果一样能用 |
| 7 | 关掉页面重新打开会话 | 结果还在 |
| 8 | 扫描一个写入 BAPI（如 `BAPI_PO_CREATE1`） | 预览里有 `?` 函数名疑似；它的源码一般不在本体里提交，所以扫描可能不报 `✗`——这时就算误登记，执行后也会被 `ROLLBACK WORK` 撤回，**但不要登记写入类函数** |
| 9 | SM37 看作业日志 | 作业名 `ZAI_RPT_<运行号>`，步骤是 `ZAI_RPT_RUNNER` |

- 把函数登记停掉：SE16 `ZAI_RPT_DEF` 把那一行的 `ACTIVE` 或 `EXEC_ENABLED` 清空，目录和执行都会拒绝。
- 代码回滚：`ZCL_AI_REPORT_EXEC_SAP` 贴回 V1.1c，`ZCL_AI_RPT_SCANNER` 贴回 V1.0b，`ZAI_RPT_REG` 贴回 V1.0a。`ZCL_AI_RFC_EXEC` 可以留着（没人调用）。报表执行不受影响：没有 `REPORT_KIND = FUNC` 的登记时，V1.2 的行为和 V1.1c 一样。
