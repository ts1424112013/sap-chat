## 2. SE11

### 2.1 `ZAI_CHAT_USER` 加字段

| 字段 | 类型 | 长度 | 说明 |
|---|---|---|---|
| AGENT_SCENES | CHAR | 40 | 开放的场景，逗号分隔（REPORT,FIORI,DATA,CODE）；空 = 全开 |

加在表末尾，激活。表里已有数据，这个字段默认为空，也就是现有用户全开，不受影响。

### 2.2 `ZAI_RPT_ACL`（新建）

交付类 A，数据浏览器 / 表视图维护选"允许显示 / 维护受限"（需要时可以生成 SM30 维护视图）。技术设置：数据类 APPL2，大小类别 0。字段直接用预定义类型。

| 字段 | 键 | 类型 | 长度 | 说明 |
|---|---|---|---|---|
| MANDT | X | CLNT | 3 | |
| USERID | X | CHAR | 12 | SU01 用户名；`*` = 所有人（公共报表） |
| SRC_TYPE | X | CHAR | 10 | REPORT（报表执行）/ FIORI |
| REPORT_ID | X | CHAR | 30 | `ZAI_RPT_DEF` / `ZAI_FRPT_DEF` 的 REPORT_ID；`*` = 这一类全部 |
| CREATED_BY | | CHAR | 12 | 谁分配的 |
| CREATED_AT | | CHAR | 14 | YYYYMMDDhhmmss |

字段名都避开了 DDIC 保留字（不用 TYPE / USER / LABEL / MODE）。

## 4. SEGW

给已有函数导入 `SaveUser` 加 3 个参数，都是 `Edm.String`，Nullable。HTTP Method 不变（POST）。

| 参数 | 长度 | 说明 |
|---|---|---|
| `Scenes` | 不设 | 例如 `REPORT,FIORI` |
| `Reports` | 不设 | 例如 `REPORT:ZDPMM702,FIORI:SHIPMENT`；超过 3000 字符时前端先存进 `ChatTexts`，参数里只放 `@@ZAI_TEXT:<编号>` |
| `AccessSet` | 1 | `X` = 本次一起保存授权 |

- 参数名区分大小写。
- 前端靠 `$metadata` 里 `SaveUser` 有没有 `Scenes` 来判断是否显示授权维护。没加之前，开关卡和「可用范围」列不显示，原有用户管理照常可用。
- 老前端不带这 3 个参数时，`AccessSet` 为空，后端不动授权。

## 5. 配置（`ZAI_CHAT_CFG`）

| 键 | 值 | 说明 |
|---|---|---|
| `RPT_ACL_ENABLED` | `X` = 开 | 按用户限制报表。不写 / 空 = 所有人看全部。界面上「设置 → 用户管理」顶部的开关读写的就是它 |

键长不超过 20 字符，`npm run test:abap` 第 1 项会检查。

## 7. 回退

- 只关报表限制：在界面上关掉开关，或清空 `RPT_ACL_ENABLED`。
- 只放开某个用户的场景：在「可用范围」里四个都勾上（存为空）。
- 完全回退：重贴上一版 AGENT（V15.10）、DPC（V15.11）、CHAT（V2.5）、REPORT（V1.0.15）、FIORI（V1.0.1）、COMBO（V1.0），SEGW 删掉 3 个参数后 Generate。新字段、新表和 `ZCL_AI_ACCESS` 可以留着，不影响别的功能。

## 8. 可能遇到的问题

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 激活 `ZCL_AI_ACCESS` 报 `AGENT_SCENES` 未知 / `ZAI_RPT_ACL` 未知 | 字段没加或表没激活 | 按 §2 补 |
| 保存可用范围提示 "Invalid Function Import Parameter 'Scenes'" | SEGW 没加参数或没 Generate | 按 §4 核对参数名（区分大小写） |
| 用户管理里看不到「可用范围」列 | `$metadata` 里 `SaveUser` 没有 `Scenes`（SEGW 没加，或浏览器缓存了旧的 metadata） | 加参数后 Generate；`/IWFND/CACHE_CLEANUP` 清网关缓存，浏览器强制刷新 |
| 保存后提示"用户已保存, 但授权保存失败" | `ZAI_RPT_ACL` 写入失败 | SE16 检查表；看 ST22 |
| 开了开关，普通用户报表目录是空的 | 还没给他分配报表，也没有公共报表 | 在「可用范围」分配，或给「所有人」勾公共报表 |
| 用户在「自动」里说"这个能力没有开放给你" | 问题要用到他没开的报表执行 / 数据分析 | 设计如此；需要就在「可用范围」里开通 |
| 「自动」里还是查到了表 | AGENT 不是 V15.12（现场类没加「自动」收窄那两段） | 搜 `lv_auto_deny` 核对 |
