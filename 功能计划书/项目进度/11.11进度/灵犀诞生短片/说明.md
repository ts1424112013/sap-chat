# 灵犀诞生（完整版，2 分 10 秒，纯音乐）

自动播放的动画页面，主角是橙色像素小人。讲灵犀是怎么生出来的：一个问题 → 一个念头 → 38 天、235 次提交 → 走进 SAP → 回头看星 → 接住那句话 → 灵犀。

它把两版合在了一起：星空版的内容（真实的日期和提交、三个名字、长出工具、上线、看星、星聚成字），加上重剪版的卡点（每一记重音完成一个动作）。

## 怎么看

双击 `index.html`，点画面开始。没有声音或画面不动时运行下面的命令，再打开 http://localhost:8094/ 。

```bash
node serve.mjs
```

按键：空格暂停或继续，左右键跳到上一段 / 下一段，R 重播，F 全屏，D 打开检查面板，方括号键以 10 毫秒为单位校准画面和声音。静帧用 `?at=秒数` 打开。

## 卡点的规矩

- 每拍 0.53141 秒，鼓点进入的 17.10 秒是第 32 拍，小节第一拍是 4 的倍数。
- 成长段 57 记重音（第 32、34……144 拍），收束段 25 记（第 176……224 拍）。偶数记是小节第一拍的底鼓，奇数记是小节中间的轻敲。原曲这两段没有突出的重拍，底鼓和轻敲是在混音里加的。
- 每一记重音完成一个动作，动作从落拍那一刻才开始。东西是「蹦」出来的：落拍那一帧最大最亮，约 0.2 秒收住。小人是落拍起跳的一段连贯快动作：0.18–0.32 秒到位，腾空收脚、带拖影、落地一顿。
- 引子和间奏没有加重音，画面跟着原曲自己的几个重音走。

每一记重音的时刻在 `final-beats.js`，画面和声音共用；每一记对应的动作在 `index.html` 的 `STEPS` 和 `FSTEPS` 里，按 D 打开检查面板可以逐记对照。

## 哪些是真实数据

- `DAYS`：2026-10-05 到 11-11 这 38 天每天的提交次数（`git log` 统计），合计 235 次。每颗星是一次提交。
- `DAYJ`：成长段每一记重音走到第几天。
- 日期：10.22 报表结果抓取、10.24 更名 Momo、10.27 更名灵犀、11.08 一天 25 次提交、11.09 部署到 SAP。
- 现场问题 13 条：11.10 的问题记录条数。

示意的部分：事务码墙、工单编号、「12 行」、后面飞来的七个问题。查询的日期由 `ORDER_DATE` 控制。

## 音轨

`music-final.m4a` 由 `gen_final.cjs` 生成：原配乐 130 秒不剪，只在两段鼓点里加重音；进门前把音乐压下去一整小节，进门那一记最重。

```bash
afconvert -f WAVE -d LEI16@44100 -c 1 "../../11.10进度/灵犀品牌短片/music.m4a" /tmp/lingxi-source.wav
node gen_final.cjs /tmp/lingxi-source.wav /tmp/lingxi-final.wav && afconvert -f m4af -d aac -b 192000 /tmp/lingxi-final.wav music-final.m4a
```

## 主角

16×10 格的像素小人：身体 12×8，眼睛 1×2，两侧短肢 2×2，四只脚 1×2，颜色 `#d97757`。一格 12 像素（看星时 16，回望来路的全景里 3）。造型按 Claude 像素小人的公开形象画，没有对照过参考图片。
