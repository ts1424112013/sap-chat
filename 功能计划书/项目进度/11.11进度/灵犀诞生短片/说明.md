# 灵犀短片：诞生（2 分 10 秒，纯音乐）

自动播放的动画页面，主角是橙色像素小人，只有配乐和画面里的字。整部片子只讲一件事：灵犀是怎么生出来的。没有章节标题，一路连下去。

## 内容

| 时间 | 画面 | 画面里的话 |
|---|---|---|
| 0–17 秒 | 黑暗里一颗橙色像素跳两下，拉成一道金线，「每一个工具，都从一个问题开始。」从线上升起；镜头扎进事务码里，上百个事务码迎面飞过，减速后落成一面墙。一句「ABG1 工厂今天开了多少工单？」在里面找不到入口 | 答案，都在 SAP 里。／可想问一句，得先知道敲哪个事务码。 |

没有底部字幕。话写在画面里：衬线字，一个字一个字浮出来，关键词是金色。墙的场景放在左上角；原野和星空放在左侧，上面三行小字是日期、第几天、已经升起的星数；结尾那句在「灵犀」正下方。

## 哪些是真实数据

- 每天的提交次数：`index.html` 开头的 `DAYS`，是 2026-10-05 到 2026-11-11 这 38 天的 `git log` 统计，合计 235 次。片中每颗星对应一次提交，在它发生的那一天升起；天数和总数都是从这个数组算出来的。
- 日期：10.24 更名 Momo、10.27 更名灵犀、11.09 部署到 SAP，取自提交记录和项目进度。
- 六样工具对应已经做出来的功能：对话里画图、报表、定时任务、读写 Excel、看代码、读写 Word 文档。

示意的部分：事务码墙是随手排的常见事务码；「第一行代码」那一行不是仓库里的原文；「12 张工单」和记录里的编号是虚构示例；后面飞来的七个问题是举例。仓库的第一次提交是 10.05 的基线，项目动手的时间比这略早，片中只说「2026 年 10 月」。

要更新数字，重新统计后改 `DAYS` 即可：

```bash
git log --format='%ad' --date=short | sort | uniq -c
```

## 主角

16×10 格的像素小人：身体 12×8，眼睛 1×2，两侧短肢 2×2，四只脚 1×2，颜色 `#d97757`。每个镜头里一格的像素数是整数（诞生和看星 16，其余 12），姿态变化都以整格为单位。造型按 Claude 像素小人的公开形象画，没有对照过参考图片。

## 配乐

`music.m4a` 是参考视频 `视频.mp4` 的原声轨（130 秒），只在最后 5 秒加了淡出。

## 播放

浏览器直接打开 `index.html`，点画面开始。没有声音或画面不动时运行下面的命令，再打开 http://localhost:8094/ 。

```bash
node serve.mjs
```

按键：`空格` 暂停 / 继续，`←` `→` 上一段 / 下一段，`R` 从头播放，`F` 全屏。地址后面加 `?at=秒数` 可以直接看某一刻的静止画面。

录成 MP4：全屏播放时录屏。Mac 自带录屏录不到电脑声音，先录无声画面，再在 iMovie 里把 `music.m4a` 从开头对齐拖进去。

## 修改

都在 `index.html` 里，按片中时间（秒）驱动：

- 画面里的话：`NARR`，每条是「开始秒、结束秒、位置、第一行、第二行」，`*…*` 之间的字是金色。
- 每一段是一个函数：`scOpen`、`scWall`、`scBirth`、`scWorld`（成长的五个小场景）、`scNight`、`scReturn`、`scEnd`。
- 小人走到哪里：`POS`；目光、短肢、挥手、点头、小跳：`LOOK`、`ARMS`、`WAVE`、`NODS`、`HOPS`。
- 星星：`sky` 函数；哪一天在片中的哪一秒：`TDAY`。
