# 灵犀短片：诞生、过程、结果（2 分 10 秒，纯音乐）

自动播放的动画页面，主角是橙色像素小人，只有配乐和字幕。讲的是灵犀这个项目本身是怎么来的，数字都取自仓库的提交记录。

## 内容

| 段 | 时间 | 画面 | 字幕 |
|---|---|---|---|
| 序 | 0–17 秒 | 一行字打出来：「每一个工具，都从一个问题开始。」随后是满墙的事务码，一句「ABG1 工厂今天开了多少工单？」在里面找不到入口 | 答案都在 SAP 里。／可想问一句话，得先知道该敲哪个事务码。 |
| 一 · 诞生 | 17–33 秒 | 金色指针（屏幕另一头的人）打出「能不能，直接问？」；像素从事务码墙上飞来拼成小人；第一行代码打出；头顶挂上最早的名字 | 2026 年 10 月，有人换了个问法。／于是，第一行代码写了下来。／它最早的名字，叫 Gale-SAP。 |
| 二 · 过程 | 33–76 秒 | 一天一根柱子、一块砖是一次提交。小人一天跳一根，金色指针在前面垒砖；路过里程碑时举手，没有提交的日子打个盹；左上角是第几天和累计提交数 | 从那天起，每天往上垒一点……／先学会查数据、看报表……／名字换过三次……／后来，它能自己拆任务…… |
| 回头看 | 76–93 秒 | 全景：38 根柱子和「38 天 235 次提交」；然后是小人和金色指针的对话，13 条现场问题逐条打勾 | 它不是一次写成的。／是一个人和一个 AI，一句一句聊出来，一条一条改出来的。 |
| 三 · 结果 | 93–118 秒 | 灵犀工作台；开头那句话直接问出「12 张工单」和 Excel；两侧列出六项能力；底部四个数字 | 现在，那句话可以直接问了。／不用记事务码。说出来，就有结果。 |
| 谢幕 | 118–130 秒 | 小人站在「灵犀」旁边挥手 | 灵犀／让想法成为结果。 |

## 哪些是真实数据

- 每天的提交次数：`index.html` 开头的 `DAYS`，是 2026-10-05 到 2026-11-11 这 38 天的 `git log` 统计，合计 235 次。天数、总数、最高的一天（11.08，25 次）都是从这个数组算出来的。
- 柱子上的里程碑（`FLAGS`）：日期取自提交记录和项目进度——10.05 Gale-SAP 起步、10.09 对话里能画图、10.20 权限自助、10.22 报表结果抓取、10.24 更名 Momo、10.27 更名灵犀、10.28 任务边跑边看、11.01 组合分析、11.04 定时任务、11.08 新引擎、11.09 部署到 SAP、11.10 23 个内置技能。
- 13 条现场问题：11.10 下午的问题记录条数。

示意的部分：事务码墙是随手排的常见事务码；「第一行代码」那一行是示意，不是仓库里的原文；结果段的「12 张工单」沿用之前短片的虚构示例。仓库的第一次提交是 10.05 的基线，项目动手的时间比这略早，片中只说「2026 年 10 月」。

要更新数字，重新统计后改 `DAYS` 即可：

```bash
git log --format='%ad' --date=short | sort | uniq -c
```

## 主角

16×10 格的像素小人：身体 12×8，眼睛 1×2，两侧短肢 2×2，四只脚 1×2，颜色 `#d97757`。每个镜头里一格的像素数是整数（过程段 12、诞生和谢幕 16、对话特写 20、全景 3），姿态变化都以整格为单位。造型按 Claude 像素小人的公开形象画，没有对照过参考图片。

## 配乐

`music.m4a` 是参考视频 `视频.mp4` 的原声轨（130 秒），只在最后 5 秒加了淡出。

## 播放

浏览器直接打开 `index.html`，点画面开始。没有声音或画面不动时运行下面的命令，再打开 http://localhost:8094/ 。

```bash
node serve.mjs
```

按键：`空格` 暂停 / 继续，`←` `→` 上一段 / 下一段，`R` 从头播放，`F` 全屏。地址后面加 `?at=秒数` 可以直接看某一刻的静止画面。

录成 MP4：全屏播放时录屏。Mac 自带录屏录不到电脑声音，先录无声画面，再在 iMovie 里把 `music.m4a` 从开头对齐拖进去。

## 修改

都在 `index.html` 里，按片中时间（秒）驱动：

- 字幕 `CAPS`，章节标题 `TITLES`。
- 每一段是一个函数：`scOpen`、`scWall`、`scBirth`、`scBuild`、`scWide`、`scTalk`、`scResult`、`scEnd`。
- 小人在每一段的位置和大小在 `actor` 函数里；目光、点头、小跳、挥手在 `LOOK`、`NODS`、`HOPS`、`WAVE`。
- 过程段的节奏：`T0`（开始时刻）和 `DT`（每天多少秒）。
