# 灵犀诞生（重剪版，1 分 31 秒，纯音乐）

自动播放的动画页面，主角是橙色像素小人。全片讲灵犀怎么从一个念头长出来，围绕开头那句「能不能，直接问？」展开。没有章节标题；除了三句发问和最后一句话，画面里没有解说文字。

节奏是「静下来 → 一步步长起来 → 再静下来」。中段每一记重音完成一个动作，手法参考《卡点视频.mp4》。

## 怎么看

双击 `index.html`，点画面开始。没有声音或画面不动时运行下面的命令，再打开 http://localhost:8094/ 。

```bash
node serve.mjs
```

按键：空格暂停或继续，左右键跳到上一段 / 下一段，R 重播，F 全屏，D 打开检查面板，方括号键以 10 毫秒为单位校准画面和声音。静帧用 `?at=秒数` 打开。

## 卡点的规矩

逐帧量过参考视频之后定的：

- 小节：鼓点进入的 17.10 秒是第 32 拍，每拍 0.53141 秒，小节第一拍是 4 的倍数。
- 中段 39 记重音，落在第 32、34、36……拍：偶数记是小节第一拍的底鼓，奇数记是小节中间的轻敲。原曲这一段没有突出的重拍，底鼓和轻敲是在混音里加的。
- 每一记重音完成一个动作，动作从落拍那一刻才开始，落拍之前不动。
- 东西是「蹦」出来的：落拍那一帧最大最亮，约 0.2 秒收住。
- 小人是落拍起跳的一段连贯快动作：起步最快，0.18–0.32 秒到位，腾空收脚、身后带拖影、落地一顿。两记重音之间它呼吸、眨眼，目光先看向下一处。
- 只有四记重音镜头往前轻轻一顶（接住那句话、托住脚、递出去、进门）；只有一次切镜（回头看来路）；只有一次光漫全屏（进门）。没有大字。
- 开头和收尾没有重音，画面慢慢走。

每一记重音的时刻在 `cut-beats.js`，画面和声音共用；每一记对应的动作在 `index.html` 的 `STEPS` 里，按 D 打开检查面板可以逐记对照。

## 音轨

`music-cut.m4a` 由 `gen_cut.cjs` 从原配乐重新编排：

- 0–17.10 秒：原曲 0–17.10 秒，做了柔化、压低音量。
- 17.10–29.85 秒：原曲同一段。
- 29.85 秒起：跳到原曲 48.98 秒接着走（都在小节线上），这样「走进 SAP」正好落在原曲鼓点退场前最后一个小节的第一拍。
- 进门前抽掉两拍；进门那一记最重。之后顺着原曲进入安静段，并去掉 140 赫兹以下的低频。
- 74.5 秒起：接回原曲开头的旋律，最后 3.5 秒渐弱。

压缩成 m4a 之后和原始波形的偏移是 0 毫秒。

重建（macOS）：

```bash
afconvert -f WAVE -d LEI16@44100 -c 1 "../../11.10进度/灵犀品牌短片/music.m4a" /tmp/lingxi-source.wav
node gen_cut.cjs /tmp/lingxi-source.wav /tmp/lingxi-cut.wav && afconvert -f m4af -d aac -b 192000 /tmp/lingxi-cut.wav music-cut.m4a
```

## 实测

正常速度完整连播一遍：37 记有声的重音，画面平均比音频晚 4.8 毫秒，最多 11 毫秒（一帧约 16.7 毫秒），没有一记早于声音。

这个数字量不到声音从设备里出来的延迟。有线耳机和外放可以忽略；蓝牙耳机通常让声音晚 100–250 毫秒，用方括号键校准。

## 主角

16×10 格的像素小人：身体 12×8，眼睛 1×2，两侧短肢 2×2，四只脚 1×2，颜色 `#d97757`，一格 12 像素（全景那一小节是 4 像素）。造型按 Claude 像素小人的公开形象画，没有对照过参考图片。

## 示意数据

事务码墙是随手排的常见事务码；工单编号、「12 行」是虚构示例。三个名字和它们的顺序是真实的（Gale-SAP → Momo → 灵犀）。
