# 灵犀诞生试剪（16.8 秒）

双击 `index.html`，点击开始。也可以在本目录运行 `node serve.mjs`，再打开 http://localhost:8095/ 。

空格暂停或继续，左右键跳到相邻镜头，R 重播，F 全屏。D 打开对拍检查，方括号键以 10 毫秒为单位调画面。校准为正时画面提前。静帧可以用 `?at=秒数` 打开。

画面跟随音频时间。保留配乐的旋律，前后收掉低频和尖锐的打击声。中段从脚步的轻鼓开始，合表之后加入更密的短打，最重一拍前留出短停，交付后只留余音。四个动作中，折文件接在轻鼓上，其余三个落在主重拍。

| 试剪时间 | 动作 | 镜头变化 |
| --- | --- | --- |
| 6.964 秒 | 正确的记录浮上来，接住小人并把它抬高 | 从错行特写切回全景，踏板之间连出金线 |
| 9.088 秒 | 六条记录同时排进表格 | 切到表格与小人同框，走过的路留在画面里 |
| 13.338 秒 | 文件到达金色指针 | 镜头落在交付处，文件停住，出现「已收到」 |

订单编号是示意数据。重建 WAV 可以在 macOS 运行以下命令。

```bash
afconvert -f WAVE -d LEI16@44100 -c 1 ../music.m4a /tmp/lingxi-source.wav
node build_trial.cjs /tmp/lingxi-source.wav trial.wav
```
