# 灵犀介绍视频（给业务用户，约 1 分 30 秒）

自动播放的动画页面：8 个画面，中文配音（macOS 自带的「婷婷」）+ 字幕。界面是按灵犀样式重画的，数据都是示例（工厂 1001、料号 A-10021 等），不含公司真实数据。

| 段 | 画面 | 讲什么 |
|---|---|---|
| 1 | 开场标志 | 灵犀是什么：查报表、看数据、出文件 |
| 2 | 提问 → 参数卡 | 直接问，灵犀找报表、预填工厂和日期，核对后提交 |
| 3 | 结果分析 | 接着问排名、汇总，先结论再表格图表 |
| 4 | 结果接力 | 料号一键带进下一张报表 |
| 5 | 文件夹 | 读写 Excel / Word，写前确认，可撤回 |
| 6 | 过程可见 | 每一步看得见，内置业务技能 |
| 7 | 安全 | 用你的权限，只查不改，不绕过权限 |
| 8 | 结尾 | 像问同事一样，问 SAP |

## 播放

浏览器直接打开本文件夹里的 `index.html` 就行（Safari、Chrome、Edge 都可以）。如果双击打开后没有声音或画面不动，在终端里运行：

```bash
node serve.mjs
```

然后打开 http://localhost:8092/ 。

点画面开始播放。按键：`空格` 暂停 / 继续，`←` `→` 上一段 / 下一段，`F` 全屏，`R` 从头播放，`H` 隐藏底部进度条，`C` 开关字幕。

## 录成 MP4（Mac 自带录屏，不用装软件）

1. 打开页面，按 `F` 全屏，按 `H` 隐藏进度条。
2. 按 `Cmd + Shift + 5`，选「录制整个屏幕」；在「选项」里把麦克风选成「无」。
   - 录屏默认**不录电脑声音**。要把配音录进去，有两种办法：
     - 用 QuickTime Player →「文件」→「新建屏幕录制」，同样录不到系统声音；需要装 BlackHole 等虚拟声卡才能录系统声音。
     - **推荐**：先录无声画面，再在 iMovie 里把 `audio/` 下的 8 段配音按顺序拖进去（每段开头对齐画面切换），或者直接把视频交给剪辑同事配。
   - 公司电脑如果是 Windows：按 `Win + Alt + R`（Xbox Game Bar）录屏，**会录到系统声音**，最省事。
3. 点「录制」，回到页面按 `R` 从头播放，播完（约 1 分 30 秒）停止录制。

## 修改

- 改旁白：编辑 `script.json`（`say` 是念的文字，数字写成「一零零一」这类读法；`cap` 是字幕文字），然后运行 `python3 gen_audio.py` 重新生成配音和时长。
- 改画面：编辑 `template.html`（每段是一个 `<section>`，元素上的 `data-t` = 在本段配音的百分之多少时出现）。
- 改完运行 `python3 build.py` 生成 `index.html`。地址后面加 `?at=秒数` 可以直接跳到某个时间点看静止画面。
