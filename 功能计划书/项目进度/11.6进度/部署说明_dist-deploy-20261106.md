# 部署说明：dist-deploy-20261106.zip（前端精简包）

构建自 main `0fa2da2`（2026-11-06）。`config.js` 为 `mode: "backend"`，同源访问（`host` 留空）。

## 包里有什么

SAP 上的前端还是 10-28（`676cea6`）的版本。本包一次带上之后的**全部前端改动**，即《04-前端实施文档》〇-Z 表里的各节：

| 节 | 内容 | 要后端先上吗 |
|---|---|---|
| 〇-P / 〇-Q / 〇-R | 技能工单补零、结果刷新后不丢、思考模式 | 思考模式要《03》〇-Q |
| 10-30 修复 | QAS 登录 403（XHR 换令牌、401 / 403 提示分开） | 不用 |
| 〇-T / 〇-U / 〇-S / 〇-V / 〇-W / 〇-X / 〇-AA | 组合分析、用户可用范围、权限固定值、函数目录、F4、表参数粘贴、定时任务 | 各自要《03》同名节 |
| 〇-AC | 报表接力：参数卡显示预填值、结果卡「和结果 X 关联」 | 要《03》〇-AC |
| **〇-AD**（新） | 参数卡**多重选择**：粘贴 Excel 一列、粘贴面板、值多了收起 | 不用 |
| **〇-AE**（新） | 参数卡填到一半**切换会话 / 刷新后值还在** | 不用 |

后端没上的功能，前端按 `$metadata` 探测不到就不显示按钮，其余照常可用，所以**前端可以先上**。
