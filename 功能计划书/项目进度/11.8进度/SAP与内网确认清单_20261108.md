## 二、ADT 能不能用（ADT 方案 M0）——决定 ADT 开不开工

用**开发账号**登录灵犀（HTTPS），在**同一个浏览器**新开标签页，地址栏依次打开（`<主机:端口>`、`<客户端>` 换成你们的）：

1. `https://<主机:端口>/sap/bc/adt/discovery?sap-client=<客户端>`
   → 应看到一大段 XML。看不到：SICF 里 `/sap/bc/adt` 没激活。
2. `https://<主机:端口>/sap/bc/adt/repository/informationsystem/search?operation=quickSearch&query=ZCL_AI*&maxResults=10&sap-client=<客户端>`
   → 应看到灵犀自己的几个类。**右键另存这页 XML 带回来**（按真实格式写解析）。
3. `https://<主机:端口>/sap/bc/adt/oo/classes/zcl_ai_agent_http/source/main?sap-client=<客户端>`
   → 应看到源码。
4. 换一个**没有开发权限**的普通账号重复第 3 步 → 应是 403（说明权限由 SAP 把关）。
5. （新增，数据分析用）域固定值：`https://<主机:端口>/sap/bc/adt/ddic/domains/<一个有固定值的 Z 域名>?sap-client=<客户端>` → 能看到固定值即可；没有合适的 Z 域可以用标准域 `MTART` 以外任意一个带固定值的域试。
6. （新增，数据分析用）CDS 源码：如果你们有 Z 开头的 CDS 视图，打开 `https://<主机:端口>/sap/bc/adt/ddic/ddl/sources/<CDS名>/source/main?sap-client=<客户端>` → 能看到源码即可；没有 CDS 就跳过。

带回：每步能 / 不能 + 第 2 步的 XML。
（草稿源码语法检查是 POST 请求，地址栏测不了，开工后我在代码里测。）
