## 二、发现并已修复的高危 Bug

**问题**：早期版本用户开通校验字段错误（3 处）

**位置**：
- ZCL_AI_CHAT_SERVICE.abap:435（analyze 入口）
- ZCL_AI_AGENT_SERVICE.abap:193（analyze_agent 入口）
- ZCL_AI_SQL_GUARD.abap:398（SQL 工具开关）

**根因**：  
表 `zai_chat_user` 的登录 ID 字段是 **USERID**（`sy-uname`），  
`USERNAME` 是显示姓名。早期代码曾误用 `WHERE username = sy-uname`。

**后果**：  
所有正常用户会被"没有权限"拦截，除非某人的显示名恰好等于登录账号。

**修复**：  
已将 3 处全部改为 `WHERE userid = @sy-uname AND active = 'X'`，  
并确认全库无残留 `username = sy-uname`。
