## 常见问题

### Q: 为什么要改存 sessionStorage？
A: localStorage 在浏览器关闭后仍存在，一旦被 XSS 注入就能偷走密码。sessionStorage 浏览器关闭即删除，风险更低。

### Q: 为什么要校验会话归属？
A: 不校验的话，知道任何人的会话 ID 就能读对方的聊天记录。这叫 IDOR（越权访问）漏洞。

### Q: 为什么新增用户开通字段？
A: 方便后期限制：只给特定用户开通 SQL 工具，防止滥用。

### Q: 动态 SQL 为什么要词法扫描？
A: 虽然是"只读"操作，但如果不校验的话，攻击者可能在 SQL 里注入 ABAP 代码来做其他事情（比如修改对象）。

### Q: 什么时候可以用新的 SQL 工具？
A: 本周修复完、下周代码实现完、下下周测试。预计月中可用。
