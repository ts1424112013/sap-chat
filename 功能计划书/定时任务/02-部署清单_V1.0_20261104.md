## 4. SEGW

四个函数导入：Return Type Kind = Complex Type，Return Type = `GenericResult`，Cardinality = 1；参数全部 `Edm.String`、Nullable。参数名区分大小写。

| 函数导入 | HTTP Method | 参数 |
|---|---|---|
| `ScheduleSave` | **POST** | `ScheduleJson`（不设长度）、`ClientRequestId`（32） |
| `ScheduleList` | GET | `Scope`（10） |
| `ScheduleAction` | **POST** | `ScheduleId`（32）、`Action`（20）、`Note`（120） |
| `ScheduleRuns` | GET | `ScheduleId`（32） |

- `ScheduleJson` 编码后超过 3000 字符时，前端先存进长文本通道 `ChatTexts`，参数里只放 `@@ZAI_TEXT:<编号>`。
- 前端看 `$metadata` 里有没有 `ScheduleSave` 决定显示不显示侧栏「定时任务」和结果卡上的「设为定时」。SEGW 没建之前，界面和原来一样。

## 5. 配置（`ZAI_CHAT_CFG`）

| 键 | 建议值 | 说明 |
|---|---|---|
| `SCHED_ENABLED` | `X` | 总开关；关掉后保存被拒，已有作业到点直接结束 |
| `SCHED_MAX_PER_USER` | 不写，默认 10 | 每人最多几个定时任务 |
| `SCHED_MIN_HOURS` | 不写，默认 1 | 每 N 小时的最小 N |
| `SCHED_WAIT_MIN` | 不写，默认 30 | 报表执行等结果的上限（分钟） |
| `SCHED_KEEP_RUNS` | 不写，默认 30 | 每个定时任务保留几条运行记录 |

键都不超过 20 字符（`npm run test:abap` 第 1 项检查）。还依赖已有的 `TASK_CONTEXT_ENABLED = X`（定时跑报表要挂在任务上）。

## 6. 权限

- 用户要能**释放自己的后台作业**（`S_BTCH_JOB`，JOBACTION = RELE）。能执行报表的用户本来就有；没有时保存会提示"你没有释放后台作业的权限"。
- 作业以创建人身份运行，查表、报表授权、函数授权都和他手动操作一样，不需要技术用户。

## 7. 现场验证

先用自己的账号、一个每小时跑的定时任务观察两三次，再开放给用户。

| # | 操作 | 应看到 |
|---|---|---|
| 1 | 侧栏出现「定时任务」，点开 → 新建：名称「测试」、指令「统计今天 ZAI_CHAT_MSG 有多少条消息」、场景「数据分析」、触发「每 N 小时」N = 1，从当前时间后几分钟开始 → 创建 | 列表有这一行，显示下次运行时间。SE16 `ZAI_SCHEDULE` 一行、`ZAI_SCHED_TRIG` 一行（JOBNAME / JOBCOUNT 有值）；SM37 有作业 `ZAI_SCHED_<号>_1`，状态「已释放」，周期 1 小时，用户是自己 |
| 2 | 等到点 | SM37 作业完成；侧栏「定时任务」有角标 1；侧栏多一个会话「定时：测试」（时钟图标 + 蓝点）；会话里一条「【定时运行】…」、指令（作为提问）和灵犀的回答；列表里「上次 成功」；展开有一条运行记录 |
| 3 | 打开专属会话 | 蓝点和角标消失（`LAST_SEEN_AT` 更新） |
| 4 | 报表执行跑一次 ZDPSD021，结果卡下方点「设为定时」 | 设置框带出数据来源和这次的参数；场景固定为「报表执行」；高级设置里只有日期参数可以改成相对日期 |
| 5 | 把日期改成「昨天」、指令写「看库存最高的前 10 个料号」→ 创建 → 列表点「立即运行」 | 专属会话里先出结果卡，再出分析；运行记录的参数是换算后的具体日期 |
| 6 | 在第 4 步的设置框里试图改非日期参数（直接改请求） | 后端拒绝："参数「…」不能在这里修改" |
| 7 | 暂停 → SM37 | 作业被删除；列表状态「已暂停」，没有下次运行时间；恢复后作业重建 |
| 8 | 管理员「全部用户」→ 停用某人的定时任务（写原因） | 对方列表显示「管理员停用」和原因；到点作业运行后直接结束，不产生运行记录 |
| 9 | 新建时触发选「每周」只勾今天以外的日子，用「立即运行」之外的方式等到点 | 作业照常每天启动，但当天不该跑 → 直接结束，没有运行记录 |
| 10 | 没有释放作业权限的测试用户新建 | 提示没有 S_BTCH_JOB 权限，不落库 |
