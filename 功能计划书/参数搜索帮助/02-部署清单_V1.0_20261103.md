# 参数卡搜索帮助（F4）：部署清单

> **2026-11-04 补充**：本清单写的是本批当时的版本。之后几批又改了其中一些对象（例如 `ZCL_AI_AGENT_SERVICE` 已到 V15.15、`ZCL_ZAI_CHAT_DPC_EXT` 已到 V15.14）。**几批一起上 SAP 时，请按 `docs/03-后端实施文档.md`〇-Z 的总清单只贴最终版本**；本清单的表结构、SEGW、验证和回滚说明仍然有效。

版本：V1.0；编写日期：2026-11-03（Asia/Shanghai）。对应《01-方案与开发计划》V1.0。代码已在仓库里，**还没上 SAP**。

## 0. 前置

- `ZCL_AI_RPT_SCANNER` V1.2 是在 V1.1a（RFC 函数执行批）上改的，`scan_function` 引用 `ZCL_AI_RFC_EXEC`。**RFC 函数执行批的核心对象要先上**（《RFC函数执行/02-部署清单》§1 前 5 行）。
- `ZCL_ZAI_CHAT_DPC_EXT` 仓库版带着之前几批没上 SAP 的改动（组合分析、思考模式、用户权限等）。那几批没上时，**不要整类重贴**，按 §3 手工只加一个分支。
- `ZCL_AI_VALUE_HELP` 不依赖用户权限批：报表授权是动态调的，`ZCL_AI_ACCESS` 不存在就跳过。

## 2. SEGW 函数导入

- 名称：`ValueHelp`
- Return Type Kind：Complex Type，Return Type：`GenericResult`，Cardinality 1
- HTTP Method：**GET**
- 参数（全部 `Edm.String`，都可为空）：`ReportId`、`ParamId`、`Query`
- 生成运行时对象（MPC 重新生成即可，DPC_EXT 不会被覆盖）

前端看 `$metadata` 里有 `ValueHelp` 才调用。没加时参数卡和原来一样，不会报错。

## 3. 激活顺序

1. （可选）SE11：`ZAI_RPT_PARAM` 加 `REF_FIELD` CHAR 61，激活（表调整）。
2. SE24：重贴并激活 `ZCL_AI_RPT_SCANNER` V1.2。
3. SE24：新建 `ZCL_AI_VALUE_HELP`，源代码视图整类粘贴，激活。
4. SEGW：加函数导入 `ValueHelp`（§2），生成。
5. SE24：`ZCL_ZAI_CHAT_DPC_EXT`
   - 前几批都已上 SAP：整类重贴 V15.13。
   - 前几批没上：在 `execute_action` 的 `CASE` 里、`WHEN 'ANALYZECODE'.` 前面加仓库版 `WHEN 'VALUEHELP'.` 那一段（约 20 行，从 `" V15.13: 参数卡搜索帮助` 到 `ENDIF.`），其余不动。
6. 前端随下一次部署上。
7. （可选）已登记的报表重新登记一次（`ZAI_RPT_REG` 写入登记），把 `REF_FIELD` 存下来，打开参数卡时就不用再扫描源码。

### 激活 / 运行时可能遇到的

| 现象 | 原因 / 处置 |
|---|---|
| `shlp_descr` / `ddshselopt` / `seahlpres` 某个字段不认识（如 `intdescr-issimple`、`f4field`） | 字段名是按印象写的，SE11 看实际结构，改 `get_shlp` / `shlp_select` 那一行，告诉我回填 |
| 搜索帮助列表总是空、状态行写「搜索帮助 … 取值失败(…)」 | `F4IF_SELECT_VALUES` 参数名和本系统不一致。SE37 看它的接口（`SHLP` / `MAXROWS` / `CALL_SHLP_EXIT` / `RECORD_TAB` / `RECDESCR_TAB`），把不一样的告诉我 |
| 列表里编号是空的或截断 | 记录拆分按 `RECDESCR_TAB-OFFSET ÷ charsize` 取，个别搜索帮助偏移不同。告诉我是哪个搜索帮助 |
| 参数没有小方块按钮 | 这个参数没有字典参照（`TYPE c LENGTH 4` 这种），或参照的字段没有搜索帮助 / 检查表 / 固定值。SE16 看 `ZAI_RPT_PARAM-REF_FIELD`；没加列时看扫描预览 |
| 所有参数都没有按钮 | SEGW 没加 `ValueHelp` 或没生成（浏览器 `$metadata` 里搜 `ValueHelp`） |

## 4. 现场验证

| # | 操作 | 预期 |
|---|---|---|
| 1 | 「报表执行」里执行 ZDPMM702 | 参数卡里工厂、机种显示字典文字（不再是 `WERKS` / `MODEL`）；有搜索帮助的框右侧有小方块 |
| 2 | 点工厂的小方块 | 弹层列出工厂编号 + 名称，底部写「共 N 条 · 搜索帮助 H_T001W」（或检查表 T001W） |
| 3 | 搜索框输入工厂名称的一部分 | 列表按名称过滤 |
| 4 | 点一行 | 填进输入框，弹层关闭 |
| 5 | 多值参数（如 ZDPPP059 的工厂）点小方块，勾两个，点「填入（2）」 | 输入框是 `1000,2000`；再打开，这两个已勾上 |
| 6 | 物料号参数选一个 | 填进去的是带前导零的内部格式（报表下发选择表要这个格式），列表里显示不带零 |
| 7 | 焦点在输入框里按 F4 | 同点小方块 |
| 8 | 普通用户（`RPT_ACL_ENABLED` 开着、没分配这张报表） | 弹层写「没有报表 … 的使用权限」 |
| 9 | 选一个有固定值的参数（域有固定值的字段） | 状态行写「固定值 <域名>」 |

## 5. 回滚

- 只关功能：SEGW 删掉 `ValueHelp` 函数导入（或不生成），前端就不显示小方块。
- 代码回滚：`ZCL_AI_RPT_SCANNER` 贴回 V1.1a；`ZCL_ZAI_CHAT_DPC_EXT` 删掉 `VALUEHELP` 分支；`ZCL_AI_VALUE_HELP` 可以留着（没人调用）。`REF_FIELD` 列留着不影响任何东西。
