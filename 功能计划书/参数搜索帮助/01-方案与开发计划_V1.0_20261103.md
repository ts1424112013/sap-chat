# 参数卡搜索帮助（F4）：方案与开发计划

版本：V1.0；编写日期：2026-11-03（Asia/Shanghai）。用户确认「直接按建议做」。

## 1. 要解决的问题

报表执行的参数卡（「需要填写参数」）现在只是普通输入框。SAP GUI 选择屏里，工厂、物料、供应商这类字段旁边有个小方块，点开就能搜、能选。灵犀里没有，用户只能凭记忆手填。

另外，截图里的参数显示 `WERKS` / `MODEL`，没有字典文字。

## 2. 现状

| 环节 | 现状 |
|---|---|
| 参数登记 `ZAI_RPT_PARAM` | 存了名称、类型、长度、默认值等，**没存字典参照**（`p_werks TYPE t001w-werks` 里的 `T001W-WERKS`）。扫描器解析时看得到，用它取了字段名称，但没保存 |
| 后端 | 没有取候选值的接口 |
| 前端 `AskCard` | 普通 `sap.m.Input` / `DatePicker` |

## 3. 方案

### 3.1 字典参照从哪来

1. **新登记**：扫描器 V1.2 把参照写进 `ZAI_RPT_PARAM` 新列 `REF_FIELD`（CHAR 61）。列是按名字动态写的，SE11 没加这列时照常登记，只是不存参照（和 `GROUP_LABEL` 同样的做法）。
   - 报表：`TYPE` / `LIKE` / `FOR` 后面的引用。引用是程序里的变量（`FOR gv_werks`、`FOR gs_alv-werks`）时，在源码里找它的 `DATA … TYPE x` 再换成字典名，最多追两层。
   - 函数：接口参数的参照类型（`FUPARAREF-STRUCTURE`）；范围表取 `LOW` 的类型。
   - 只存能在字典里解析的（`cl_abap_typedescr=>describe_by_name` 成功）。
2. **已登记的**（没有 `REF_FIELD`）：打开参数卡时，后端现场扫描一次源码（报表走扫描器 `scan`，函数走 `read_interface`），不用重新登记。

### 3.2 取候选值（新类 `ZCL_AI_VALUE_HELP`）

前端只传「报表编号 + 参数编号 + 关键字」。表名和字段由服务端从登记里推出，**不接受前端传表名**。

按顺序取，取到就停：

| # | 来源 | 做法 |
|---|---|---|
| ① | 域固定值 | `DD07V`，按关键字过滤值或文字 |
| ② | 标准搜索帮助 | 表字段 `F4IF_DETERMINE_SEARCHHELP`；只有数据元素时 `DD04L-SHLPNAME` + `F4IF_GET_SHLP_DESCR`。集合搜索帮助展开后取第一个基本帮助。`F4IF_SELECT_VALUES` 无弹窗取值，**不调搜索帮助出口**（出口可能弹窗，HTTP 会话里会 dump）。关键字先按编号 `CP *关键字*`，不够再按文字列搜 |
| ③ | 检查表 / 值表 | 表字段的检查表或域的值表；有文本表（`DD08L` FRKART = TEXT）读当前语言文字，没有就取检查表里第一个较长的字符列（如 T001W-NAME1） |

- 每次最多 100 条，多了提示「只显示前 100 条，请输入关键字缩小范围」。
- 返回 `key`（内部格式，提交用）+ `display`（输出格式，转换例程 `_OUTPUT`）+ `text`（名称）。填进输入框的是 `key`，因为报表执行下发选择表用内部格式（如物料号带前导零）。
- 所有 `F4IF_*` 调用包在 `TRY … CATCH cx_sy_dyn_call_error`，动态 SQL 包在 `CATCH cx_sy_dynamic_osql_error cx_sy_open_sql_db`，任何一步失败就落到下一个来源，最后返回「没有可选值」，不 dump。
- 关键字里的单引号转义（`cl_abap_dyn_prg=>escape_quotes`），`%` / `_` 用 `ESCAPE '#'`。

### 3.3 权限

- 报表登记必须存在且活动。
- 报表授权：动态调 `ZCL_AI_ACCESS=>REPORT_OK`（用户权限批没上 SAP 时类不存在，跳过）。
- 候选值本身和 GUI 一样不另做权限过滤：GUI 里 F4 能看到的，这里就能看到。

### 3.4 接口（SEGW 新函数导入 `ValueHelp`）

`GET ValueHelp?ReportId=…&ParamId=…&Query=…`，返回 `GenericResult`。

- `ParamId` 为空 → **元数据**：这张报表哪些参数有搜索帮助，以及字典文字（补 `WERKS` 这种没名称的标签）。
  `{"reportId","params":[{"paramId","hasHelp","label","ref"}]}`
- `ParamId` 有值 → **搜索**：
  `{"reportId","paramId","source":"SHLP|CHECK|FIXED","sourceName","keyLabel","textLabel","items":[{"key","display","text"}],"truncated"}`

前端看 `$metadata` 里有 `ValueHelp` 才调用，没部署时参数卡和现在一样。

### 3.5 前端

- 有搜索帮助的输入框改用 `Input` 的值帮助按钮（输入框右侧的小方块，和 GUI 一样）。范围参数「从」「至」各有一个。
- 点开是自绘弹层：顶部搜索框（输入后 300ms 自动搜），下面列表「编号 + 名称」，底部一行来源说明（如「搜索帮助 H_T001W · 前 100 条」）。
  - 单值：点一行就填进去、关闭。
  - 多值：点行勾选，底部「填入（N）」追加到输入框（已填的保留、去重）。
- 字典文字：元数据里有 `label`、而卡片上标签等于参数编号时，换成字典文字。
- 演示模式：`MockBackend` 给演示报表的工厂、物料、供应商、库存地点几组数据。
- 浅色 / 深色截图验证。

## 4. 对象清单

| 类型 | 对象 | 动作 |
|---|---|---|
| SE11 | `ZAI_RPT_PARAM` | 加列 `REF_FIELD` CHAR 61（可选；不加也能用，走现场扫描） |
| 类 | `ZCL_AI_VALUE_HELP` | 新建 |
| 类 | `ZCL_AI_RPT_SCANNER` | V1.2：`ty_param` 加 `ref_field`、`deref`、save 写 `REF_FIELD` |
| 类 | `ZCL_ZAI_CHAT_DPC_EXT` | V15.13：`WHEN 'VALUEHELP'` |
| SEGW | `ZAI_CHAT` | 新函数导入 `ValueHelp`（GET，ReportId / ParamId / Query，返回 GenericResult） |
| 前端 | `AskCard` / `App.controller` / `ChatService` / `MockBackend` / CSS | 小方块按钮 + 弹层 |

## 5. 已知限制

- 不调搜索帮助出口：依赖出口过滤 / 补数的搜索帮助（少数）结果会比 GUI 多或空，空时退到检查表。
- 集合搜索帮助只用第一个基本帮助（GUI 里是多个页签）。
- 不带 GUI 里的「依赖字段」联动（比如库存地点按已填工厂过滤）。
- Fiori 报表参数卡（`kind = FIORI`）一期不做。
