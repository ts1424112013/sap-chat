SAP 上目前运行的是 **2026-10-13 的代码**（10.11 的 A+B+C 三批已随它上线，见 [00_对象清单与部署顺序_20261011.md](00_对象清单与部署顺序_20261011.md)）。本文列出 10-13 之后的全部改动，**等三项新功能写完后一起部署**（小风 10-19 决定）。三项新功能的对象在开工后追加到本文第七节。

本目录仍是后端 ABAP 源码的唯一事实源；文件都是累积版本。

## 二、部署步骤（按顺序）

1. **先跑一次测评基线并存档**（改进清单 PROC-04；设置 → 测评），作为部署前后对比。
2. **SE24** `ZCL_AI_AGENT_GUARD` → 按文件头 `★ 重贴后核对标记` 检查 → 激活（公共接口不变，任何时候单独激活都行）。
3. **SE24** `ZCL_AI_LLM_CLIENT` → 核对标记 → 激活。重贴前在 SE37 看一眼 `ENQUE_SLEEP` 的形参名是不是 `SECONDS`（不一样也能激活，运行时会退化为"不等待直接重试"）。
4. **SE24** `ZCL_AI_REPORT_SERVICE` 和 `ZCL_AI_REPORT_EXEC_SAP` 互相引用 → 两个都贴好后**一起批量激活**。
   ⚠ 改进清单红线 2：`EXEC_SAP` 重贴前先和 SAP 上现有版本对比（线上应为 V1.0e）。
5. **SE24** `ZCL_AI_AGENT_SERVICE` → 核对标记 → 激活（依赖第 2–4 步）。
6. **SE38** 新建 `ZAI_TEST_AGENT_CORE` → 贴入 `tests/ZAI_TEST_AGENT_CORE.abap` → 激活 → **F8，末行应为"全部通过"**。
7. **前端**：`npm run build` → 把 dist 部署到 SAP。
8. 复跑测评并存档，和第 1 步对比。

激活顺序依据：AGENT_SERVICE 引用 GUARD、LLM_CLIENT、REPORT_SERVICE；GUARD / LLM_CLIENT 不引用本批其他对象（踩坑清单 §2.5）。

## 三、配置项
